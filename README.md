# Vendor blobs for the Xiaomi Pad 8 (yupei)

The vendor tree for `yupei` is too large for GitHub and is hosted on GitLab:

**https://gitlab.com/sidharthify/android_vendor_xiaomi_yupei** (branch `seventeen`)

Clone it into `vendor/xiaomi/yupei` in your ROM checkout:

```
git clone https://gitlab.com/sidharthify/android_vendor_xiaomi_yupei \
    -b seventeen vendor/xiaomi/yupei
```
